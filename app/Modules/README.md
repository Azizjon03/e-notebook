# Modullar

Kod yo'nalishlar bo'yicha bo'lingan (modulli monolit). Har modul o'z modellari,
servislari, controllerlari va testlariga ega bo'ladi.

| Modul | Vazifasi |
|---|---|
| Core | Foydalanuvchi, auth, ball va daraja, eslatma dvigateli |
| Onboarding | Ro'yxatdan o'tish oqimi (ism, joylashuv, jins) |
| Geo | Mintaqalar, joylashuvdan mintaqani aniqlash |
| Planner | Kunlik vazifalar, kalendar, rejalashtirish vaqti |
| Routine | Namoz vaqtlari, uyqu |
| Sport | Qadam, zal dasturlari |
| Study | O'qish sessiyalari |
| Ilm | Kitoblar, sahifa progressi |
| Work | Ish vazifalari |
| Telegram | Webhook, buyruqlar, xabar yuboruvchi |

Har bir so'rov joriy foydalanuvchi bilan cheklanadi: bir foydalanuvchi boshqasining
ma'lumotini ko'rmaydi.
